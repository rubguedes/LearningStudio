✨ Sobre o projeto
O LearningStudio é um aplicativo desktop para Windows que reúne organização de estudos, trilhas de idiomas e desenvolvimento de carreira em IA, com acompanhamento de progresso e tutores inteligentes opcionais.
🧭 Funcionalidades
🌍 Trilha de Idiomas
- Plano de estudos personalizado por idioma, nível, prazo e disponibilidade.
- Lições com leitura, redação, vocabulário e correção por IA.
- PDFs para estudar e anotar no Samsung Notes; importação para correção.
- Reforço de erros recorrentes e Relembrar com revisões espaçadas.
- Percurso visual com etapas e checkpoints, inspirado na experiência de progressão do Duolingo.
💻 Trilha de Carreira
- Roadmap de competências para AI Engineer e AI Solutions Architect.
- Conteúdo teórico fundamentado em fontes verificáveis, com exemplos e desafios práticos.
- Exercícios de Python e TypeScript com testes e feedback por IA.
- Integração planejada com GitHub para desenvolver o portfólio.
- Currículo com sugestões de melhoria e vagas com análise de aderência.
📅 Organização e IA
- Dashboard de metas, tarefas, sessões e progresso.
- Lembretes com Google Calendar e Gmail, mediante autorização.
- Importação manual de tarefas do ChatGPT, sem prometer sincronização automática.
- IA opcional via OpenAI API ou Ollama, com controle de consumo.
- Estudos e materiais disponíveis localmente mesmo sem internet.
🛠️ Tecnologias previstas
Área	Tecnologia
Desktop	Tauri 2
Interface	React + TypeScript + Vite
Camada nativa	Rust
Banco de dados	SQLite
IA	OpenAI API / Ollama
Distribuição	Instalador .exe
